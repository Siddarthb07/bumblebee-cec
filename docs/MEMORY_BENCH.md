# Memory / scale bench

Generated by `python -m bumblebee.cli bench --mode memory`.

This bench answers 'how far does CEC scale on memory vs modern LLMs?' It does not claim answer-quality parity with frontier models.

## Scale reading

- CEC peak RSS **0.399 GB** vs Mistral-7B FP16 weights (~14 GB): **0.0285×**
- vs Llama-3.1-70B FP16 (~140 GB): **0.0028×**
- vs 405B-class FP16 (~810 GB): **0.0005×**
- Closest catalog FP16 footprint: `gpt2`

CEC **beats** these FP16 weight footprints on raw memory:

- gpt2-medium
- SmolLM-360M
- Pythia-410M
- Llama-3.2-1B
- Llama-3.2-3B

- GPT-4-class (public est.)

## Honesty

- Catalog rows are **weight-only**; real LLM inference adds KV cache and framework overhead.
- CEC headline params may include sparse hash rows; do not equate to dense transformer FLOPs.
- Quality is scored separately (`bench --mode all`); this card is **memory scale only**.
